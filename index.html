Resumen

Factura del pedido

Se genera a partir de las líneas y precios de "(WH) 3. Pedido Wholesale". Marca el cliente como internacional para eximir el IVA (exportación / operación intracomunitaria); a los clientes nacionales se les aplica el IVA configurado en Reglas/Config.

Reglas de conversión SKU

La app parte cualquier código por guiones: el primer trozo es la base, y de los trozos siguientes identifica cuál es el material (comparándolo contra las listas de abajo) — el que quede es la talla. No importa el orden ("BASE-L-ORO" o "BASE-ORO-L" se interpretan igual). Si ningún trozo coincide con una palabra de material, se asume el material por defecto.
